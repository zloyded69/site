# Доска «Обо мне»

Интерактивная доска с карточками (Цвет, Место, Еда, Напиток, Хобби, Машина,
Цветы, Животное, Персонаж). При нажатии карточка переворачивается, показывая
фото.

## Общий доступ

Сайт подключён к бесплатной базе Firebase Realtime Database — фото, которые
загружает автор, видят все посетители сайта, на любом устройстве, включая
GitHub Pages. Обновление происходит само, без перезагрузки страницы.

## Пароль автора

В файле `index.html` найди строку:

```js
const OWNER_PIN = "2609";
```

Поменяй `2609` на свой пароль перед публикацией.

## Как выложить на GitHub Pages (без командной строки)

1. Зайди на github.com и создай новый **публичный** репозиторий (New repository).
2. В репозитории нажми **Add file → Upload files** и загрузи `index.html`.
3. Сделай коммит (Commit changes).
4. Зайди в **Settings → Pages**.
5. В разделе **Build and deployment** выбери **Deploy from a branch**,
   ветку `main`, папку `/ (root)`, сохрани.
6. Через минуту-две сайт появится по адресу вида:
   `https://твой-логин.github.io/название-репозитория/`

## Как выложить через git (командная строка)

```bash
cd photo-board
git init
git add index.html
git commit -m "Доска обо мне"
git branch -M main
git remote add origin https://github.com/ТВОЙ_ЛОГИН/НАЗВАНИЕ_РЕПО.git
git push -u origin main
```

Потом включи GitHub Pages так же, как в шагах 4–6 выше.

## Про безопасность базы данных

Правила Firebase сейчас открыты (`.read: true, .write: true`) — это упрощённый
режим для доски с друзьями, а не банковский уровень защиты. Кнопки
редактирования на сайте защищены паролем, но теоретически кто-то технически
подкованный может писать в базу напрямую через API. Для личного проекта это
обычно приемлемо.
